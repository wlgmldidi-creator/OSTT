# OST — ONLY STREAMING 공식 소개 사이트

## 파일
- `index.html`: 페이지 구조 및 콘텐츠
- `style.css`: 프리미엄 골드 테마와 모바일 반응형 스타일
- `script.js`: 팀원 카드, 프로필 모달, 모바일 메뉴

## GitHub Pages 배포
1. GitHub에서 새 공개 저장소를 만듭니다(예: `ost-only-streaming`).
2. 이 폴더의 파일 4개를 저장소 최상위에 업로드합니다.
3. 저장소의 **Settings → Pages**로 이동합니다.
4. **Deploy from a branch**를 선택하고 `main` 브랜치 및 `/ (root)`를 지정한 뒤 저장합니다.
5. 잠시 후 표시되는 GitHub Pages 주소로 접속합니다.

## 멤버 프로필 수정
`script.js` 상단의 `members` 배열에서 각 멤버의 `bio`를 수정하고 `spoonUrl`에 스푼라디오 프로필 주소를 입력하세요. 각 멤버의 스푼라디오 프로필 주소가 `script.js`의 `spoonUrl`에 입력되어 있습니다. 프로필 카드 클릭 시 상세 소개 모달이 열리고, 스푼라디오 프로필 버튼을 누르면 해당 멤버의 주소로 이동합니다.


## 멤버 일러스트
`assets/` 폴더에 멤버별 이미지가 포함되어 있으며, 파일명 기준으로 프로필 카드와 상세 프로필에 연결되어 있습니다. 이미지를 교체할 때는 동일한 파일명을 유지하세요.
